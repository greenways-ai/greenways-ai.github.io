GREENWAYS OPEN SOURCE CHARTER · VERSION 1.0

Public infrastructure,
precisely stewarded.

Greenways builds durable tools in public. The charter defines what people can expect when a project carries the Greenways Open Source signature.

01 · Open by default 02 · Usable freedom 03 · Public stewardship 04 · Interoperability 05 · Contributors 06 · Sustainability 07 · Identity
01 · OPEN BY DEFAULT

Source, licence, and decisions are visible.

Qualifying projects publish their source in a public repository under an explicit, recognised open-source licence. The exact licence is stated by each repository; the Greenways signature never replaces or obscures it.

02 · USABLE FREEDOM

Open means useful beyond Greenways.

People may inspect, run, modify, redistribute, and use the work commercially according to its stated licence. Public source that cannot be meaningfully used is not enough.

03 · PUBLIC STEWARDSHIP

Direction is explained, not merely announced.

Greenways publishes material architectural decisions, compatibility changes, release notes, and security channels. Maintainers may lead decisively while keeping the reasoning inspectable.

04 · INTEROPERABILITY

Interfaces should outlive implementations.

Protocols, formats, and compatibility boundaries are documented. Where conformance matters, Greenways works toward executable specifications and public test suites rather than relying on branding alone.

05 · CONTRIBUTORS

Contribution is public work with public credit.

Changes are reviewed in the open whenever security and privacy permit. Contribution requirements should be documented, technically relevant, and applied consistently. Contributors retain visible credit for their work.

06 · SUSTAINABILITY

Open foundations can support a durable business.

Greenways may sell hosting, integration, support, certification, or managed experiences. Commercial services do not reduce the rights already granted by a project’s open-source licence.

07 · IDENTITY

Code freedom and project identity are separate.

Software licences govern the covered work. Greenways and project names, logos, certification marks, and claims of official compatibility remain subject to their own policies. Forks are welcome; misleading endorsement is not.

THE SIGNATURE

A Greenways Open Source Project

This phrase means the project has public source, an explicit open-source licence, visible stewardship, and a maintained relationship to this charter. It does not mean every Greenways project uses the same licence. The repository’s LICENSE file is always authoritative.
