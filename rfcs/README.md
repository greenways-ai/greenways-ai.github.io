# Greenways RFCs

RFCs capture substantial design proposals and their rationale before normative specifications change.

## File naming

```text
rfcs/0001-short-title.md
```

Numbers are assigned when a proposal is accepted for discussion.

## Required sections

- Summary
- Motivation
- Scope
- Proposed design
- Specification impact
- Compatibility
- Security and abuse considerations
- Attribution and rights implications
- Alternatives
- Migration
- Unresolved questions

## Outcomes

An RFC may be `draft`, `accepted`, `rejected`, `withdrawn` or `superseded`. Acceptance does not itself publish a stable specification. The resulting normative changes must still pass review, conformance and release requirements.
